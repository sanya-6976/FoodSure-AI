# FoodSure AI 🧪🌾

## AI-Based Turmeric Adulteration Detection & Quantification

FoodSure AI is an AI-assisted research prototype designed to investigate the detection and quantification of turmeric adulteration using multimodal machine learning.

The project combines:

- 📷 Image-based features
- 🔬 ATR-FTIR spectroscopy
- 🎨 Color measurements
- 🤖 Machine learning
- 📊 Explainable AI

---

## 🎯 Problem

Food adulteration can be difficult to identify through visual inspection alone.

This project investigates whether machine-learning models can identify turmeric adulteration and estimate the percentage of adulterant using measurable changes in visual, spectral, and color characteristics.

The current research focuses on **wheat-flour adulteration in turmeric**.

---

## 🔬 Research Questions

FoodSure AI investigates:

1. Can machine learning detect turmeric adulteration?
2. Can models distinguish different adulteration levels?
3. Can the adulteration percentage be estimated?
4. Which modality provides the most useful information?
5. Does multimodal fusion improve predictive performance?
6. Which features contribute most to model decisions?
7. How well do models generalize to unseen physical samples?
